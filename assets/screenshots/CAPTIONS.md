# Screenshot & store captions

Short lines for GitHub social preview, Stream Dock store tiles, and README screenshots.  
Hardware focus: **MiraBox N4 Pro** + **Gigabyte MO32U2**.

Pick one hero line + one support line per language.

## English

**Hero**
- Your MO32U2. Your knobs. No OSD diving.
- MiraBox N4 Pro × Gigabyte MO32U2 — HDR, brightness, crosshair, picture modes.
- Built for the N4 Pro dials and the MO32U2 panel — leave the OSD alone.

**Support**
- Dial brightness in SDR % or HDR nits — the same knob, the right unit.
- Preview picture modes while you turn; apply when you pause.
- Scene-stable dials — values stay put when you switch pages.

**CTA**
- Download the Windows install zip → drop into Stream Dock → play.
